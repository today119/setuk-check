# 세특 점검기

NEIS에서 내려받은 「과목별 세부능력 및 특기사항」 엑셀을 올리면
**기재요령 금지 내용 · 분량 초과(1,500Byte) · 오탈자**를 검사합니다.

👉 **https://today119.github.io/setuk-check/**

## 개인정보

파일은 **서버로 전송되지 않습니다.** 브라우저 안에서만 읽고 검사하며,
업로드·저장·전송이 일어나지 않습니다. 새로고침하면 사라집니다.

## 검사 기준

2026학년도 학교생활기록부 기재요령(고등학교)
- 「학교생활기록부 작성 시 유의사항」 3항 가~파
- 제13조 교과학습발달상황 — 세부능력 및 특기사항 입력 불가 항목
- 제4조③ 문자 입력 원칙

## 안내

보조 수단입니다. 최종 판단과 책임은 작성 교사에게 있습니다.
